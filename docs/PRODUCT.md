# Product Framing

## Problem

Building inspection reports contain valuable technical knowledge: findings, risks, recommendations, compliance notes, and maintenance advice. This information is often buried in long PDF documents, making it difficult for engineers to reuse previous observations when assessing a new issue.

Example questions an inspector may ask:

- Have we seen similar defects before?
- What risks were associated with them?
- What recommendations were made?
- Which report and page supports the retrieved observation?

## Target User

Primary user:

- building inspector or technical control engineer

Secondary users:

- risk engineer
- asset manager
- insurance reviewer
- compliance auditor
- public authority reviewer

## Why This Is Relevant To SECO

SECO operates in technical inspection, compliance, construction risk, and engineering advisory. These activities generate large volumes of document data that can become reusable technical intelligence if structured and indexed correctly.

This MVP demonstrates how historical inspection reports can become a searchable knowledge layer for construction risk and quality control.

## Product Value

The product helps users:

- retrieve similar historical cases faster
- reuse previous technical recommendations
- improve consistency across inspections
- identify recurring defect and risk patterns
- verify every AI result against the original source page

## Demo Narrative

An inspector searches for a technical issue such as `water leakage near roof`. The system retrieves similar observations from previous reports, shows severity and recommendations, and displays the cited report page directly in the app.
